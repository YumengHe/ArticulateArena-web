How the cabinet’s parts are connected

An articulated object has parts that can move relative to each other. Each rigid part is a link; each connection that controls their relative movement is a joint.

This simplified example adds a turning latch to the drawer, so we can follow a joint attached to another moving part.

Where does “one degree of freedom” fit?

For each moving joint here, one number sets its configuration: the drawer’s opening distance, the door’s angle, or the latch’s angle. The whole cabinet has several joints, so it needs several numbers.

The tree is a map of these connections. Articulated objects can also have closed loops; this tutorial and the paper’s tree score focus on tree structures.

From the map to the mathematicsThe metric behind the map

The map turns a joint’s movement rule and limits into two endpoint vectors. The formula below compares those endpoints in both pairings and keeps the smaller distance: the joint error E.

articulatearena implements a principled distance between articulated-kinematics predictions and ground truth. A one-DOF joint J = (ξ, [l⁻, l⁺]) with unit screw twist ξ ∈ se(3) and limits l⁻, l⁺ is represented by its unordered pair of endpoint twists {z⁻, z⁺} = {l⁻ξ, l⁺ξ}. The joint metric is the quotient distance of flat se(3) × se(3) under the swap:

E(J₁, J₂) = min{ ‖z₁⁻ − z₂⁻‖² + ‖z₁⁺ − z₂⁺‖², ‖z₁⁻ − z₂⁺‖² + ‖z₁⁺ − z₂⁻‖² }1/2,

where ‖·‖ is an injected se(3) norm. A subscript names that choice, Eα under the split norm and EB under the kinetic-energy norm, and superscripts mark the extensions Eϕ (compactified) and Etree (tree lift). The package provides the metric itself, a smooth training surrogate, the radial compactification that extends the metric continuously to unbounded (continuous) joints, and two object-level lifts: an optimal-assignment skeleton distance and a motion-aware tree edit distance with a certified assignment relaxation.

All functions are pure: norms, weights, and tolerances are passed in by the caller and never hardcoded. The library depends only on numpy, scipy, and pyyaml.
