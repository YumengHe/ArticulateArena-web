1 Describe joints

Reference + prediction

Start with two descriptions of the same object in the same stored pose. Each description gives the links, joints, motion limits, and connections. URDF is one way to store them.

Movement rule + limits

A twist ξ = (ω, v) combines the joint type, direction, and axis location into one movement rule. The coordinate q gives the amount; the limits say which amounts are allowed.

Drawer

ξ = (0, 0, 0; 1, 0, 0)

Reference: [0, 0.50] m
Prediction: [0, 0.40] m

Wheel

ξ = (0, 0, 1; 0, 0, 0)

Reference: (−∞, +∞)
Prediction: [−π, π] rad

The first three twist entries describe rotation and the last three translation. Both examples keep the same axis and zero pose on both sides. Twist definition →

Keep the two endpoints

Multiply the twist by each limit: z⁻ = l⁻ξ and z⁺ = l⁺ξ. These are two six-dimensional vectors, not points on the object.

Drawer

Reference: {0, 0.50ξ}
Prediction: {0, 0.40ξ}

Wheel

Reference: directional limits along −ξ and +ξ
Prediction: {−πξ, +πξ}

Infinite ends are directional limits, not ordinary vectors filled with infinities. Optional full-turn wrapping is a separate choice made before constructing endpoints. Endpoint representation →

2 Compare motion

Choose one norm

The split norm combines rotation and translation with a shared scale α. Both examples use α = 1 m⁻¹, so their split scores are dimensionless.

‖Δz‖α² = ‖Δω‖² + α² ‖Δv‖²

The alternative body norm uses the reference part’s mass distribution and gives EB in meters before compactification. For this drawer, EB = 0.10 m. Equal numbers need not have equal units. Compare the two norms →

Handle unlimited motion

Drawer · raw endpoints

This finite-only example keeps {0, 0.50ξ} and {0, 0.40ξ} unchanged.

Wheel · compactified endpoints

Apply the same radial map to both sides. With κ = π and ‖ξ‖ = 1:

Reference: {−ξ, +ξ}
Prediction: {−0.7616ξ, +0.7616ξ}

ϕ(z) = tanh(‖z‖ / κ) z / ‖z‖, ϕ(0) = 0

Finite endpoints stay inside the unit ball; infinite ends reach its boundary. A benchmark including unlimited joints can apply this map consistently to every joint. Compactification does not wrap an angle to one turn. Continuous joints →

Compare both pairings

Reversing an axis and its limits can exchange the endpoint labels without changing the motion. Compute both pairings using the same norm.

Drawer

Direct: √(0² + 0.10²) = 0.100
Swapped: √(0.40² + 0.50²) ≈ 0.640

Wheel

Direct: √2 (1 − tanh 1) ≈ 0.337
Swapped: √2 (1 + tanh 1) ≈ 2.491

Keep the smaller error

Drawer Eα = 0.100

Wheel Eαϕ ≈ 0.337

These are two different protocols: raw endpoints for the drawer, compactified endpoints for the wheel. Do not rank them against each other. Neither score is an average of finite point displacements over every possible pose. Endpoint matching →

3 Use the score

Report per-joint accuracy

The joint error is already an evaluation result. Report it directly, or aggregate matched-joint scores under a stated protocol. The drawer has one score of 0.100; the wheel has one compactified score of approximately 0.337.

To evaluate connections as well, use the tree branch below. A joint average does not become a tree metric merely by summing the scores.

Include the connections

Turn the predicted tree into the reference tree using substitutions, contractions, and expansions. Each edit is priced by the same chosen joint-distance rule; J₀ = {0, 0} is a fixed joint.

SubstituteE(J, J′)

ContractE(J, J₀)

ExpandE(J₀, J′)

Both examples have one correctly connected joint, so the only required edit is to substitute its motion description.

Find the least expensive valid edit sequence

Etree = min Σ edit costs

Here, the tree error equals the joint error: 0.100 for the drawer and approximately 0.337 for the compactified wheel. Larger mechanisms require structural matching; an extra joint or a wrong parent can add cost.
