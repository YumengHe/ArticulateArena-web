This cabinet is an articulated object with three main parts: the body, drawer, and door. The drawer slides and the door rotates relative to the body.

Four ideas to keep with you

Link
One rigid part.
The door, the drawer, or the body.
Joint
A connection with a motion rule.
A hinge lets the door rotate.
One degree of freedom
One number sets the joint’s state.
A distance for a slide; an angle for a hinge.
Kinematic tree
A map of the connections.
Parts are nodes. Joints are edges.
The evaluation question

Does the predicted object move and connect like the reference?

ArticulateArena measures that difference. This tutorial considers objects whose connections form a tree.
