Start with the physical object

One cabinet. Four parts. Three joints.

An articulated object has parts that can move relative to each other. Each rigid part is a link; each connection that controls their relative movement is a joint.

This simplified example adds a turning latch to the drawer, so we can follow a joint attached to another moving part.

Where does “one degree of freedom” fit?

For each moving joint here, one number sets its configuration: the drawer’s opening distance, the door’s angle, or the latch’s angle. The whole cabinet has several joints, so it needs several numbers.

The tree is a map of these connections. Articulated objects can also have closed loops; this tutorial and the paper’s tree score focus on tree structures.
