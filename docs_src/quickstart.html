The distance is 0 exactly when the two sides induce the same motion, and it is a true metric: symmetric, with the triangle inequality, and invariant to the sign of the axis and to which limit is called lower. Eα is dimensionless, EB is in meters, Eϕ is dimensionless and bounded, and Etree sums joint costs over an optimal matching. The core concepts pages explain each choice with a figure, and the API reference lists every function.
