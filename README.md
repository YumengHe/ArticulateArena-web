# ArticulateArena-web
## Documentation pages

The documentation under `docs/` is generated. Edit the fragments in `docs_src/` (one file per page, `_layout.html` is the shared frame), then rebuild and commit the output:

```bash
python scripts/build_docs.py
```

`docs_src/quickstart.html` is itself generated by `scripts/make_quickstart.py`, which assembles the six option snippets and, with `--verify /path/to/ArticulateMetrics`, runs each of them against the sample data before writing the fragment.

`docs.html` only redirects old links to the new pages.
